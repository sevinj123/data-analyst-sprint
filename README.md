# Excel Sales Data Cleaning & Dashboard

Transformed messy sales records into an analysis-ready dataset and built an interactive Excel dashboard to explore sales by city, product, month, and sales channel.

## What I Did

- Removed duplicates and standardized text, dates, and numeric values.
- Investigated missing values and documented assumptions.
- Created PivotTables, charts, and connected slicers.
- Checked data quality and dashboard totals.

## Files & Usage

- **Excel workbook:** Cleaned data, interactive dashboard, QA checks, and detailed documentation. Use the City and Sales Channel slicers to filter the dashboard.
- **PDF:** A static preview of the dashboard.

**Tools:** Excel, Power Query, PivotTables, and PivotCharts.  
**Data:** Synthetic sales data for January–June 2026.
